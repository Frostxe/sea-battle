# Морской бой — онлайн для двоих

[Открыть игру](https://sea-battle-bekster-26.brawnykoala515.chatgpt.site)

## Как играть
1. Создай комнату.
2. Нажми «Пригласить друга» и отправь ссылку.
3. Расставьте корабли и оба нажмите «Готов к бою».

Поле 10 × 10, 10 кораблей, ручная и случайная расстановка, скрытые флоты, серверная проверка ходов, восстановление игры после обновления страницы и реванш. Комната действует 7 дней.

## Загрузка на GitHub
Распакуй ZIP. Для отображения исходников в репозитории загрузи содержимое папки sea-battle, сохраняя вложенные папки. Если загрузить сам ZIP, GitHub будет хранить его как архив и не распакует исходники автоматически. При ограничении количества файлов загружай папки несколькими порциями.

## Что внутри
- app/page.tsx — интерфейс игры.
- app/globals.css — оформление и мобильная версия.
- app/api/game/route.ts — серверные запросы.
- lib/game.ts — правила, расстановка и обработка выстрелов.
- db/ и drizzle/ — схема базы данных и миграция.
- tests/ — проверки игровой логики и сетевого матча.
- scripts/, worker/ и конфигурация — сборка и сервер.

Это исходный проект React / TypeScript / Vinext с Cloudflare Workers и базой D1. Он не запускается двойным щелчком по HTML. GitHub хранит исходники; для сетевой игры требуется сервер и база данных. Обычный GitHub Pages не запускает серверную часть этой версии. Уже опубликованная игра доступна по ссылке выше.

## Локальный запуск
Установи Node.js 24 и открой терминал в папке проекта.

```sh
npm install
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_elite_harpoon.sql
npm run dev
```

Открой адрес, который напечатает терминал. Миграцию для новой локальной базы нужно выполнить один раз. У второго игрока должен быть доступ к тому же серверу; для игры через интернет используй опубликованную версию.

## Проверки
```sh
node tests/game.test.mjs
npx tsc --noEmit
```

Для локального сетевого теста временно скопируй tests/browser-integration.html в public/qa.html, открой /qa.html и запусти тест. Удали public/qa.html перед публикацией.

В архив не включены node_modules, сборки, локальные базы, данные игроков, ключи доступа и история Git. Идентификатор исходного размещения удалён из копии конфигурации.
